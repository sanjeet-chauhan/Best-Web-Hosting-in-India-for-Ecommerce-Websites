**DaStart** is fine for building and testing your store. Once real customers arrive, move up. One CPU core and 20 concurrent connections leave little room when several shoppers check out at the same time.

**DaElite** is the plan YouStable describes as built for high-traffic sites and WooCommerce. Choose it if you already get steady daily orders or run more than one store.

A few things to plan for on any of these plans:

- **Order emails.** The plans list a cap on emails per hour. A store sending order confirmations, shipping updates and password resets should connect an SMTP service through a plugin such as WP Mail SMTP, rather than relying on the server's default mail.
- **Database size.** The plans list a 1000 MB MySQL database size. A catalog of a few hundred products usually fits comfortably, but years of orders, logs and plugin data add up. Check your database size in phpMyAdmin from time to time.
- **Backup frequency.** Backups are weekly, so a restore can be up to a week old. If you take orders every day, export your orders regularly or add a daily backup plugin of your own.

All three plans are available with India or USA servers, and each comes with a 30-day money-back guarantee.

Shared plans split a server between accounts. A VPS gives your store its own CPU, RAM and NVMe storage, with full root access, so a neighbour's traffic never slows your checkout.

It is time to look at a VPS when:

- Checkout slows down during campaigns or festive sales.

- You want to install Redis, tune PHP settings or run a staging copy of your store.
- Your catalog and order history have outgrown the 1000 MB database size on shared plans.

You get root SSH, WP-CLI, Git and Composer, plus a choice of Ubuntu, Debian, AlmaLinux or Rocky Linux. CyberPanel is free, and cPanel, Plesk or DirectAdmin can be added as paid options. Root access also means some server work is yours, such as tuning caching, so ask the support team to help if you would rather not do it yourself.

## How to Set Up Your Store

1. **Pick your plan and server location** from the table at the top of this page.
